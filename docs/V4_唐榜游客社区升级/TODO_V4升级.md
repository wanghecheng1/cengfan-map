### 4️⃣ 浏览器访问你的域名 → 做 7 项人工冒烟测试（按顺序，新增第 7 项「微信必填」）

这 7 项就是 `ACCEPTANCE_V4升级.md` 里的「六、人工验证项」+ **本次补加 #7**，请逐一勾选：

- [ ] **6.1 唐榜投票 & 3 票校验**
  - ① 首页点「🎓 同学登录」→ 用一个已加入社区的同学（姓名+密码正确）登录；
  - ② 顶部点「🏆 唐榜」→ 看到「今日剩余票数 3 / 3」；
  - ③ 找到一个已入社的其他同学（不是自己）→ 点「🗳️ 投一票」→ 弹确认；
  - ④ 连续投同一人 3 次后，按钮应变成「今日 3 票用完」且 disabled；
  - ⑤ 成功时绿色大卡显示剩余票数。

- [ ] **6.2 副社长设置**
  - ① 用某社长身份登录 → 去该社区卡片点「📖 完整页」；
  - ② 成员行找到任一其他成员 → 点右侧「🌟 设为副社长」→ 确认；
  - ③ 成功后该成员显示「🌟 副社长」tag；再次点击「🌟 撤销副社长」可清除；
  - ④ 顶部身份卡也会显示「🌟 副社长：XXX」。

- [ ] **6.3 游客真的看不到真实姓名？**
  - ① 回到入口页（先 👀游客模式 banner 点退出 → 回入口）；
  - ② 点「👀 游客入口」→ 进入；
  - ③ 依次检查：同学名录 / 地图 tooltip / 点地图弹详情 / 社区完整页成员 / 唐榜 → **所有姓名都只能看到首字母（如 whc）**，找不到任何完整汉字姓名。

- [ ] **6.4 留言板真的不会连发？**
  - ① 切回用户入口（退出游客 → 用同学登录）；
  - ② 在聊天板输入任意内容 → 疯狂连点发送按钮 5~10 次；
  - ③ 消息列表应 **严格只出现 1 条**（其他被 sendingMsg 拦截）；
  - ④ 同时弹出绿色「💬 留言发送成功」卡。

- [ ] **6.5 申请创建/加入成功弹窗真的存在？**
  - ① 退社后 → 点「🏗️ 申请创建新社区」→ **现在需要填微信号（必填）+ 密码（必填）** → 提交 → 应有 5 秒绿色大卡说明审批流程；
  - ② 之后点某社区「🎯 加入」 → 同样**必须填微信号（必填）+ 密码（必填）** → 提交 → 也应有绿色提示「等社长审批」。

- [ ] **6.6 社区创建审批通过后，社区独立页可用？**
  - ① 管理员进入后台 → 「社区管理 → 申请创建」审批通过；
  - ② 创建发起人重新登录 → 进入他创建的社区「📖 完整页」→ 显示👑社长，可设副社长/转让/审批加入。

- [ ] **🆕 6.7 申请必填微信+密码真的生效？（本次补加重点验证）**
  - ① 申请创建新社区：**故意不填微信号** → 点提交 → 立即红色报错「请填写您的微信号…」，不触发网络请求 ✅
  - ② 申请创建新社区：填了微信但**密码填错** → 后端返回 401「身份验证失败，请重新登录或输入正确密码」 ✅
  - ③ 申请某社区加入：同上①② → 不填微信/密码不对都被拦截 ✅
  - ④ **管理员后台**进入「社区管理 → 申请创建 / 申请加入」两张表格 → **看到新的「📱 联系方式」列显示刚才申请人的微信号**（老申请会显示「老申请，未填微信」占位） ✅

## ✅ 清单二：管理员日常操作（你可能需要的功能速查）

### 🎯 「我要让 A 同学当副社长」
```
方式 A（社长自己操作，推荐）：
  1. 社长登录 → 点首页社区卡片的「📖 完整页」
  2. 找到 A 同学那一行 → 点右侧「🌟 设为副社长」→ 确认 → 绿色成功

方式 B（管理员兜底）：
  ★ 目前副社长 API 仅开放给社长前端按钮调用；管理员如需强制设置，
    可直接去 GitHub 仓库 data/communities.json，给对应社区对象手动加 "deputyId": A同学ID，
    然后保存 commit，1 分钟内 Netlify 就会生效。
```

### 🎯 「我要手动把副社长撤掉」
社长：进入社区完整页 → 副社长那一行 → 点「🌟 撤销副社长」即可。

### 🎯 「我要清除今天的唐榜 3 票限制，让大家重投（测试用）」
1. 去 GitHub 仓库 `data/tang-rank.json`；
2. 找到 `dailyVotes` 对象；
3. 把 `dailyVotes` 下对应今天日期的 key 删除（今天 key 是 `2026/7/30` 这种格式，按北京时间）；
4. 保存 commit → 1 分钟后大家又有 3 票。
   > 只在 测试/特殊活动 用，别随便删 :)

### 🎯 「我要把唐榜的某人票数清零（刷票惩罚）」
1. 编辑 `data/tang-rank.json`：
   - `totalVotes["该同学ID"] = 0`；
   - 可同时把 `votes` 数组里相关投票记录删除（否则下次有人投票时流水还是能看到历史）；
2. 保存 commit → 下次拉榜就显示 0 票。

## ✅ 清单四：如果出现报错 → 你可以先自己排查的 5 个常见点（新增第 5 条）

| 现象 | 可能原因 | 你可以做什么 |
|---|---|---|
| 点唐榜显示 `拉取唐榜失败：路径未匹配 POST /api/tang-rank/vote` | `netlify.toml` 的 tang-rank redirect 没推或部署失败 | 检查 deploy 日志里 netlify.toml 是否生效；确认 Site → Functions 里 tang-rank 函数确实存在。 |
| 设副社长失败：`设置副社长失败：候选人不是本社成员` | 候选人还没通过加入审批 → 成员表还没加进 memberIds | 先到社区完整页「审批加入申请 → 通过」，再设副社长。 |
| 投票失败：`仅已加入社区的同学可参与` / `未入社` | 你登录的同学档案 `communityId` 为 null | 先申请加入某个社区并通过审批 → 再登录投票。 |
| 游客下居然看到真实姓名（某处漏了） | 模板某处还在直接写 `{{ s.nickname }}` | 把那一处告诉我**具体页面 / 位置截图**，我马上加 displayNameOf 脱敏。 |
| 🆕 提交申请创建/加入：提示「请填写有效的微信号…」，但我明明填了 | 微信号长度限制 **2~50 字符**，或者开头/结尾有空格（前端 .trim() 自动去空格）。检查一下是否有 emoji 之类的特殊字符，建议用纯英文+数字的微信号或中文直接填手机号就行。如果还是报错，直接把控制台 Network 面板里 POST 请求 body 截给我看。 |
