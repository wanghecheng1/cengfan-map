### ✅ 需求 #4 · 唐榜（每人每天 3 票）
- MainPage 顶部新增 **「🏆 唐榜」** 大红入口按钮；
- **唐榜页结构**：
  - Header 红色大 banner（含刷新/返回/去社区/退出游客）；
  - **身份指示卡**：
    - 已入社：显示「今日剩余票数 X / 3」+ 今日已投名单；
    - 未入社：⚠️ 提示先加入任意社区；
    - 游客：👀 仅查看榜单；
    - 未登录：🎓 提示回首页登录。
  - **前三名 🥇🥈🥉 渐变大卡**（金/银/铜色，可直接投票）；
  - **4+ 名列表行**（#排名 / 头像 / 姓名+头衔 / 社区 / 票数 / 投票按钮）。
- **业务规则 & 校验**：
  - 每位已加入社区的同学，**北京时间 0 点重置 3 票**；
  - 未入社同学不上榜、也不能投票；
  - 不能投给自己；
  - 可连续多票投给同一人（最多 3 票）；
  - 投票按钮文案动态适配：🔒游客 / 登录后投 / 未入社 / 不能投自己 / 🗳️投一票 / 🗳️再投一票 / 今日3票用完；
  - 投票成功 → 绿色弹窗提示 + 自动刷新榜单。

## 二、新增架构资产（全局状态机）

| 名称 | 类型 | 说明 |
|---|---|---|
| `isGuestMode` | `ref<boolean>` | 全局游客模式开关，任意组件读它即可判断脱敏/禁用 |
| `currentCommunity` | `ref<Community>` | 当前社区独立页对象，由 `navigateTo('community', payload)` 注入 |
| `tangRankStore` | `reactive({rank,myRemaining,myVotedToday,loading})` | 唐榜页共享状态，避免每个组件重复拉取 |
| `successModalState` + `showSuccessModal()` | reactive + function | 全局绿色大成功弹窗，任意子组件直接调用，无需重复写模板 |
| `toInitials(name)` / `displayNameOf(student)` | 纯函数 | **统一**的姓名→首字母转换，保证所有组件脱敏一致 |

→ 这些新增资产均放在 `<script>` 最顶部（`// ========== 全局数据 & DataProvider ==========` 之前），保证任何组件都能直接访问，无任何依赖注入问题。
