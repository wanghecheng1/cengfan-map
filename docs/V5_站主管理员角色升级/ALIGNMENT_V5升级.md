## 二、边界确认（任务范围）

### ✅ IN-SCOPE（本次 V5 实现）
1. **角色模型升级**：`data/students.json` 每条记录新增字段 `role ∈ {owner, admin, student}`，后端自动迁移。
2. **原始站主初始化**：王鹤澄（nickname 精确匹配"王鹤澄"或拼音接近）自动设为 role=owner。
3. **站主后台的「角色管理」Tab（仅站主可见）**：
   - 授予任意普通同学管理员权限（role=admin，自动开启 adminFrame）
   - 撤销任意管理员（role=student，自动关闭 adminFrame）
   - 转让站主身份给任意同学（需二次确认，原站主变普通同学）
   - 开关管理员「蓝色耀眼框」adminFrame（独立于头衔系统）
4. **三级入口页**：
   - 游客入口 👀（纯只读，姓名 displayNameOf 脱敏首字母）
   - 用户入口 👥（任意同学姓名+密码，进入 MainPage）
   - 管理员入口 🛡️（仅 owner/admin 姓名+密码，直接跳 AdminPage）
5. **密码体系**：
   - owner 默认密码：`123456wHc`（仅王鹤澄初始）
   - 其他所有同学默认密码：`123456`
   - 每人（含站主）可自行**修改一次**（`passwordChangedAt` 非空即已改）
   - 管理员后台仍可重置任意同学密码（管理员特权）
6. **管理员蓝色耀眼框（adminFrame）**：
   - 独立系统：与 🏅 头衔/🎨 titleLevel 完全无关
   - 站主自动显示金色耀眼框；管理员 adminFrame=true 显示蓝色耀眼框
   - 管理员可 adminFrame=false 不显示蓝色框，但仍是管理员（权限不影响）
7. **管理员后台权限分层**：
   - 站主：全部功能 + 角色管理 Tab
   - 管理员：全部功能（审批、删除、密码管理等）**但角色管理 Tab 不显示**

### ❌ OUT-OF-SCOPE（本次 V5 不做）
1. 多站主 / 副站主模型（全站仅允许 1 位 owner）
2. 操作审计日志（谁授的管理员、谁转的站主，后续可加 data/audit.json）
3. 头衔系统升级拓展（独立 V6，再加「贡献榜 / 荣誉榜」类称号）
4. 密码找回（忘记密码 → 联系站主重置，不做邮箱/短信）
5. 二次登录（短信、验证码）

## 三、需求理解（对现有项目的理解）

### 现有架构继承
- 后端：Netlify Functions（Node.js 无服务），数据存 GitHub → `data/*.json`，通过 GITHUB_TOKEN 读写
- 前端：单文件 `index.html`，Vue 3 CDN + ECharts CDN，无构建步骤
- 现有鉴权：
  - 全局 ADMIN_TOKEN（备用超级管理员，通过 admin-login.js）
  - 同学登录：`student-login.js` 发 JWT 风格 token，`X-Student-Token` 头传递
- V4 已存在三入口雏形：游客/用户/管理员，但管理员入口当时走全局密码

### V5 与现有鉴权的兼容
- 保留**全局超级管理员**（admin-login.js + 备用密码登录），防止 owner 忘记密码锁死
- 同学 token 中增加 `role` + `isOwner` + `isAdmin` 字段，后端 `authStudentContext` 自动鉴权
- 「角色管理」后端接口强制 `requireOwner`（仅 owner 可调用），避免管理员越权

## 四、疑问澄清（已基于现有项目回答）

| 问题 | 回答（基于 project_memory + 现有代码） |
|---|---|
| 同学登录密码是否要加盐哈希？ | 代码里当前是明文存 JSON（公开仓库可控范围 + 仅站主可见密码列），保持与现状一致，避免过度设计 |
| 修改密码的「仅一次」是前端限制还是后端限制？ | **双端限制**：后端检查 `passwordChangedAt`，前端根据该字段隐藏修改按钮 |
| 转让站主需要原密码吗？ | 需求原文未提密码；加「姓名二次确认 + 弹窗确认」双层（已足够防误触） |
| 管理员后台普通同学真的一点都进不去？ | 管理员入口登录时，后端 student-login.js 校验 role ∈ {owner,admin}；否则 403 |
| 默认密码忘记了怎么办？ | ① 站主/管理员 → 后台「🔑 密码管理」重置；② 站主本人忘记 → 全局超级管理员密码备用入口 |
| adminFrame 关闭后管理员还有权限吗？ | **有**；adminFrame 仅控制"蓝色耀眼框"UI 显示，不影响 role=admin 的真实权限 |
